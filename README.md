# Loughton Private GP

Website for Loughton Private GP (loughtonprivategp.co.uk).

## Stack

React (JavaScript) + Vite, Tailwind CSS, GSAP, React Router. Hosted on Vercel.

## Run locally

```
npm install
npm run dev
```

`npm run build` creates the production build in `dist`.

## Branches

- `main`: the live Coming Soon banner (plain HTML).
- `develop`: the full React site, merged into `main` at launch.

## Folders

- `src/pages`: one file per page.
- `src/components`: layout, page sections and shared UI.
- `src/data`: page text and settings, edit content here.
- `src/assets`: self-hosted fonts and the logo.
- `public`: favicons and future videos.
